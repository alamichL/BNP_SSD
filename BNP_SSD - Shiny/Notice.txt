Modifications made in this application include:

- UI changes in `R/app_ui.R`: simplified the layout to align with our Bayesian nonparametric (BNP) approach; added a panel for displaying clustering results.
- Server logic in `R/app_server.R`: replaced parametric SSD modeling tools with a fully BNP workflow using the `BNPdensity` R package; updated all output plots accordingly.
- Application structure in `R/functions.R`: retained general-purpose Shiny utility functions; removed functions specific to parametric models and added new ones for processing BNP outputs.
- Label translation in `R/translation.R`: updated button and label names to reflect the revised interface and support user-uploaded datasets.

Additionally, the original `extdata/names.xlsx` file from `shinyssdtools`—used for dynamic label translation—has been retained with updated content matching the new user interface.

These modifications were made as part of a research project led by Louise Alamichel, Julyan Arbel, Guillaume Kon Kam King, and Igor Prünster, with the goal of improving ecological risk assessments using Bayesian nonparametric methods. At the time of development, the coding work was conducted at the Centre Inria, Université de Grenoble.
